# catalog

> Answers the current list price of products by SKU.

## 1. Boundaries

| Concern                                  | Owner                     |
| ---------------------------------------- | ------------------------- |
| Placing orders and freezing their prices | orders                    |
| Deciding who may see a price             | nobody: prices are public |

## 2. Owned Records

| Record   | Kind       | Writer                                                  | Notes                                                                            |
| -------- | ---------- | ------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Products | collection | `node-block-reference:catalog#makeInMemoryProductStore` | Held in process memory and seeded at construction; nothing writes it afterwards. |
