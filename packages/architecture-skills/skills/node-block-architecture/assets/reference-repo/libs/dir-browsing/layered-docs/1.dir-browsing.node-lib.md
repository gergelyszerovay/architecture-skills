# dir-browsing

> Lists and deletes files and prints directory trees, through a file-system port, for a CLI and an MCP server.

## 1. Boundaries

| Concern                                          | Owner                             |
| ------------------------------------------------ | --------------------------------- |
| Choosing the directory root the MCP tools browse | composition, from `FS_TOOLS_ROOT` |
| Creating the logger the audit gateway writes to  | composition                       |
| Asking the user to confirm a large deletion      | the MCP client                    |

## 3. Decisions

| ID  | Decision                                                                   | Checked by | Why                                                                                           |
| --- | -------------------------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------- |
| D1  | Every MCP tool confines its paths to the configured root; the CLI doesn't. | test       | A model browses only inside the root, while the CLI's user already has the shell's own reach. |
