# node-block-reference

> Two demonstration apps of the node-block-architecture skill: fs-tools, a CLI and MCP stdio server over the file system, and a tRPC shop.

## 1. Boundaries

| Concern                                                | Owner                                                                 |
| ------------------------------------------------------ | --------------------------------------------------------------------- |
| Keeping orders, products and events beyond the process | nobody: the in-memory repositories stand in for a database            |
| Authenticating the shop's callers                      | platform: the identity arrives in the `x-user-id` header              |
| Asking the user to confirm a large deletion            | the MCP client, which answers the server's input-required elicitation |

## 4. Decisions

| ID  | Decision                                                                                                      | Checked by | Why                                                                                       |
| --- | ------------------------------------------------------------------------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------- |
| D1  | Only the fs-tools binaries are published; the shop server runs from source.                                   | review     | The shop exists to exercise the architecture, not to ship.                                |
| D2  | The checkers load the architecture-profile skill by a relative path, from its sibling directory in the skill. | review     | The repository lives inside the skill it demonstrates, so no installed copy of it exists. |
